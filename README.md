# HCM202 React Website

## Cấu trúc

```text
hcm202-react/
├─ index.html
├─ package.json
├─ vite.config.js
└─ src/
   ├─ main.jsx
   ├─ App.jsx
   ├─ components/
   │  ├─ Navbar.jsx
   │  ├─ Hero.jsx
   │  ├─ Timeline.jsx
   │  ├─ PeriodDetail.jsx
   │  ├─ Journey.jsx
   │  ├─ QuizGame.jsx
   │  └─ Footer.jsx
   ├─ data/
   │  ├─ periods.js
   │  └─ quiz.js
   ├─ styles/
   │  └─ global.css
   └─ assets/
      └─ README.md
```

## Chạy project

```bash
npm install
npm run dev
```

## Nơi chỉnh nội dung

- Nội dung các giai đoạn: `src/data/periods.js`
- Câu hỏi game: `src/data/quiz.js`
- Giao diện timeline: `src/components/Timeline.jsx`
- Game: `src/components/QuizGame.jsx`
- CSS: `src/styles/global.css`
